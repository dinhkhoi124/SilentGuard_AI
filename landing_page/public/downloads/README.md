# Thư mục chứa các file APK của Android

Hãy đặt 3 file APK của bạn vào đây với đúng tên file như sau:
1. `app-arm64-v8a-release.apk` (Bản cho chip 64-bit)
2. `app-armeabi-v7a-release.apk` (Bản cho chip 32-bit/máy cũ)
3. `app-x86_64-release.apk` (Bản cho trình giả lập)

Khi chạy build hoặc deploy, các file này sẽ được phục vụ ở đường dẫn trực tiếp:
- `/downloads/app-arm64-v8a-release.apk`
- `/downloads/app-armeabi-v7a-release.apk`
- `/downloads/app-x86_64-release.apk`
